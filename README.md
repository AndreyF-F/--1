\# Документация к программе расчёта заказов (variant.py)



Программа `variant.py` предназначена для автоматизации работы операторов при оформлении заказов, состоящих ровно из двух позиций товаров. Программа работает линейно (пошагово), вычисляет промежуточные стоимости, итоговую сумму с учётом доставки и точный размер сдачи для клиента.



\## Как это работает (алгоритм)

1\. \*\*Сбор метаданных\*\*: Программа последовательно запрашивает имя клиента и общую тему/название заказа.

2\. \*\*Ввод позиций\*\*: Для каждого из двух товаров запрашивается название, поштучное количество и цена. 

3\. \*\*Финансы\*\*: Оператор вводит фиксированную стоимость доставки и сумму наличных денег, переданных клиентом.

4\. \*\*Математический блок\*\*:

&#x20;  \* Вычисляется стоимость каждой позиции: \\(Количество \\times Цена\\).

&#x20;  \* Суммируется общая чистая стоимость товаров.

&#x20;  \* К чистой стоимости прибавляется доставка (получаем общую сумму к оплате).

&#x20;  \* Подсчитывается сумма штук всех товаров.

&#x20;  \* Рассчитывается сдача: \\(ВнесеннаяСумма - Итого К Оплате\\).

5\. \*\*Формирование чека\*\*: На экран выводится структурированный текстовый бланк заказа. Все денежные поля автоматически округляются до 2 знаков после запятой.

\## Пример тест-кейса и ручной расчёт (Верификация)



Для проверки корректности вычислений проведем ручной расчёт на тестовых демонстрационных данных.



\### Исходные параметры для теста:

\* \*\*Название заказа:\*\* Доставка электроники

\* \*\*Имя заказчика:\*\* Алексей Иванов

\* \*\*Позиция 1:\*\* Беспроводная мышь | \*\*Кол-во:\*\* 2 шт. | \*\*Цена:\*\* 1250.50 руб.

\* \*\*Позиция 2:\*\* Коврик для мыши | \*\*Кол-во:\*\* 3 шт. | \*\*Цена:\*\* 450.00 руб.

\* \*\*Стоимость доставки:\*\* 350.00 руб.

\* \*\*Внесено покупателем:\*\* 5000.00 руб.



\### Математический ручной расчёт:

1\. \*\*Стоимость Позиции 1\*\*: \\(2 \\times 1250.50 = 2501.00\\) руб.

2\. \*\*Стоимость Позиции 2\*\*: \\(3 \\times 450.00 = 1350.00\\) руб.

3\. \*\*Общая стоимость товаров\*\*: \\(2501.00 + 1350.00 = 3851.00\\) руб.

4\. \*\*Общая сумма к оплате (с доставкой)\*\*: \\(3851.00 + 350.00 = 4201.00\\) руб.

5\. \*\*Общее количество единиц\*\*: \\(2 + 3 = 5\\) шт.

6\. \*\*Сдача\*\*: \\(5000.00 - 4201.00 = 799.00\\) руб.

```text
Внесено покупателем:              5000.00 руб.

```
